# Optional KiCad carrier

The default AquaSense build is **Gravity cables on a screw-terminal breakout**. You do not need this folder.

If you later want a carrier PCB, start from [../pinmap.md](../pinmap.md). GPIO 4 and 5 must remain unconnected. GPS SKU: I2C is 16/17, not 21/22.

A full KiCad project is not required to build the buoy.
