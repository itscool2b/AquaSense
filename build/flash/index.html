Step 3 of 9

Flash the board

USB-A to USB-C only. LilyGO will not power from USB-C to USB-C. Remove the microSD card first — SD uses GPIO 2, which fights the USB bootloader.

Install PlatformIO

VS Code + PlatformIO, or the CLI:

pip install platformio
cd firmware
pio run -e lilygo-t-a7670g -t upload
pio device monitor -e lilygo-t-a7670g

Arduino IDE path

Board: ESP32 Dev Module, PSRAM enabled, huge app partition. Install TinyGSM-fork (lewisxhe), not mainline TinyGSM. Define TINY_GSM_MODEM_A7670 and TINY_GSM_FORK_LIBRARY. First Windows/macOS connect may need the CH9102 driver from the LilyGO repo.

Do not jumper GPIO 4 (PWRKEY) or GPIO 5 (RST). On battery, firmware must hold GPIO 12 HIGH or the board resets.

After boot, serial waits 12 seconds for cal so you can calibrate without the board sleeping. See step 5.

Checkpoint. Serial monitor prints AquaSense boot and the one-sentence idea. If upload fails, take the SD card out and use a USB-A port.
