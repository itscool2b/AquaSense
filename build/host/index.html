Stand up your website

A solar buoy that sits on the water, measures a few stats, uses cellular internet to send them to a website you host. This step is the website. We do not run one.

The LTE radio cannot see this laptop. The simulator is how you test the website. The buoy only POSTs if ingest_url is a public https:// address (your VPS or a tunnel in front of port 8080).

Install Docker Desktop (or Docker Engine). From the repo:

cd selfhost
cp .env.example .env
docker compose up --build

Open http://127.0.0.1:8080. Then, in another terminal:

python3 scripts/simulate-buoy.py

Refresh the dashboard. You should see gauges, 24h/7d charts, and a map pin. No hardware yet. For a full day of chart points:

COUNT=96 python3 scripts/simulate-buoy.py

The buoy cannot see localhost

The T-A7670G uses LTE. It will never reach 127.0.0.1 on your laptop. The simulator is for you. For a real POST, put this same compose stack on a VPS (or a tunnel in front of port 8080) and use an https:// URL in config.json. Optional: the same app on your Netlify or VPS — not ours.

Checkpoint. Localhost dashboard shows a reading after the simulator. Token in selfhost/.env matches what you will put on the SD card.
