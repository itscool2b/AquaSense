Config the SD card

FAT32 microSD. Copy firmware/data/config.example.json to the card as config.json. Real tokens never go in git.

{
  "ingest_url": "https://YOUR-HOST/api/v1/ingest",
  "device_id": "buoy-01",
  "token": "change-me",
  "apn": "iot.1nce.net",
  "sample_period_s": 900,
  "p_atm_mbar": 1013.25,
  "stay_awake": false
}
  • ingest_url — your public HTTPS ingest, not localhost, not an AquaSense cloud (there isn’t one).
  • token — same string as INGEST_TOKEN in selfhost/.env.
  • apn — 1NCE default is iot.1nce.net. Other SIMs: use the carrier APN.
  • sample_period_s — 900 is a 15-minute FDEP-style cadence.
  • stay_awake — true skips the 12 s window and stays in serial calibration mode (desk). Leave false on the water.

Insert the SIM before first battery power. Eject the SD card before the next USB flash.

Checkpoint. You can open config.json on a computer and the URL is yours. After boot, serial says it loaded the file (or warns if it did not).
